# Starbucks Beverage Analytics Dashboard | Power BI

## 📌 Project Overview

This project is an interactive **Power BI dashboard** that analyzes Starbucks beverage nutritional information and product categories. The dashboard provides insights into calories, sugar, caffeine, protein, and beverage distribution, helping users understand nutritional trends across Starbucks menu items.


---

## 🎯 Objectives

- Analyze Starbucks beverage nutritional data.
- Compare beverage categories based on calories, caffeine, sugar, and protein.
- Identify beverages with the highest caffeine content.
- Visualize beverage category distribution.
- Build an interactive dashboard using Power BI.

---

## 📊 Dashboard Features

### KPI Cards
- Total Beverages
- Average Calories
- Average Sugar
- Average Caffeine

### Interactive Filters
- Protein Range Slider
- Beverage Preparation Type

### Visualizations
- Average Calories by Beverage Category
- Starbucks Global Presence
- Beverage Category Distribution
- Average Caffeine by Category
- Top 5 Highest Caffeine Beverages

---

## 📁 Dataset

The dataset contains Starbucks beverage nutritional information including:

- Beverage Name
- Beverage Category
- Beverage Preparation
- Calories
- Sugar
- Protein
- Caffeine

## 🛠 Tools & Technologies

- Power BI Desktop
- Power Query
- DAX

---

## 📈 Key Insights

- Coffee contains the highest average caffeine.
- Classic Espresso beverages are among the highest caffeine drinks.
- Tazo Tea Drinks contain lower average caffeine.
- Beverage categories are evenly distributed with Coffee having significant nutritional variation.
